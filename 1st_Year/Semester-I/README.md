# 💻 C Programming Lab Index

## I. Basics & Mathematical Expressions

    01. Basic Statistics: Finding the sum and average of three numbers.

    06. Expression Evaluation: Computing the algebraic expression $\frac{ax+b}{ax-b}$.

    09. Control Structures: Performing arithmetic operations using a switch statement.

## II. Number Theory & Logic

    02. Digit Analysis: Calculating the sum of individual digits of a positive integer.

    03. Sequence Generation: Generating the first $n$ terms of the Fibonacci sequence.

    04. Prime Discovery: Generating all prime numbers between $1$ and $n$.

    Properties & Checks:

        05. Armstrong Number: Checking if a number equals the sum of its own digits raised to the power of the number of digits.

        07. Perfect Number: Checking if a number equals the sum of its proper divisors.

        08. Strong Number: Checking if a number equals the sum of the factorials of its digits.

## III. Functions & Recursion

    10. Factorial (Iterative): Finding the factorial of an integer using a non-recursive function.

    11. Factorial (Recursive): Finding the factorial of an integer using a recursive function.

    12. Greatest Common Divisor (Recursive): Finding the GCD of two integers using recursion.

    13. Greatest Common Divisor (Iterative): Finding the GCD of two integers using a non-recursive function.

## IV. Arrays & Matrix Operations

    14. List Extremes: Identifying both the largest and smallest numbers in an array.

    15. Sorting: Implementing a program to sort an array in ascending order.

    Matrices:

        16. Symmetry Check: Determining whether a given matrix is symmetric.

        17. Matrix Addition: Performing the addition of two matrices.

        18. Matrix Multiplication: Using functions to multiply two matrices.

## V. String Manipulation & Pointers

    19. Sub-string Operations: Functions to insert a sub-string at a specific position or delete $n$ characters from a given string.

    20. Palindrome Check: Using user-defined functions to check if a string reads the same backwards.

    21. Pattern Matching: Displaying the index where sub-string $T$ begins in string $S$, or returning $-1$.

    22. Text Analysis: Counting the number of lines, words, and characters in a block of text.

    23. Pointer Arithmetic: Calculating the length of a string using pointers.

## VI. Structures & File Handling

    24. Complex Numbers: Using structures and functions for:
        - Reading
        - Writing
        - Addition
        - Multiplication

    Files:

        25. Data Retrieval: Displaying the contents of a file.

        26. File Replication: Copying the contents of one file to another.

        27. File Merging: Combining two files into a third destination file.

        28. File Modification: Reversing the first $n$ characters within a file.
